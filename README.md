# Download-pdf-books

两个浏览器油猴脚本：机械工业出版社页面收集工具，以及科学文库官方整书下载助手。

科学文库新版直接使用网站的**整书离线下载**入口，不依赖逐页截图、模拟按键或前台滚动。下载速度取决于网站、网络和浏览器；脚本不承诺具体速度。

## 选择脚本

| 脚本 | 适用网站 | 工作方式 | 下载结果 |
| --- | --- | --- | --- |
| [科学文库官方下载助手](./sciencereading-official-download.user.js) | `book.sciencereading.cn` 的图书详情页和阅读页 | 检查下载权限，提交官方整书离线下载请求 | 官方提供的文件，通常需要 KXReader |
| [机械工业电子书下载器 v0.8](<./机械工业电子书下载器 (cmpkgs.com) - 自动滚动收集-0.8 (1).js>) | `dcd.cmpkgs.com` | 捕获阅读器收到的 PDF 页面，自动滚动后用 pdf-lib 合并 | 已捕获页面合并出的 PDF |

这两个网站使用不同的阅读器和下载流程，请安装对应脚本。原有机械工业出版社脚本保留不变。

## 科学文库：安装与使用

### 安装

1. 在桌面浏览器安装 Tampermonkey（油猴）。
2. 新建脚本，把 [sciencereading-official-download.user.js](./sciencereading-official-download.user.js) 的完整内容复制进去并保存。若浏览器直接打开 `.user.js` 文件，也可以按油猴安装提示操作。
3. 在油猴设置中启用下载功能，允许 `pdf` 扩展名，并按浏览器提示授予下载权限。
4. 刷新已打开的科学文库阅读页或详情页。页面右下角应出现“官方整书下载”面板；也可以从油猴菜单启动下载。

使用脚本本身不需要安装 Node.js、npm 或其他依赖。

### 下载《航空无损检测概论》

- [图书详情页](https://book.sciencereading.cn/shop/book/Booksimple/show.do?id=B4D5A0AF3C41D4B6DE063010B0A0AE2D0000)
- [在线阅读页](https://book.sciencereading.cn/shop/book/Booksimple/onlineRead.do?id=B4D5A0AF3C41D4B6DE063010B0A0AE2D0000&readMark=0)

1. 使用具有下载权限的账号登录。详情页的官方“下载”按钮可用于确认下载资格。
2. 点击脚本面板的 **后台下载整书**。
3. 下载启动后可切换标签页或最小化窗口，无需逐页滚动。保留浏览器和该标签页，直到下载完成；关闭标签页、浏览器休眠或系统休眠可能中断下载。
4. 查看脚本状态和浏览器下载记录。下载管理器报告完成后，核对文件大小并使用网站指定的阅读器打开，检查是否能访问首尾及中间章节。

**官方文件格式：**检查到的详情页说明下载文件需使用 **KXReader** 打开，文件有效期为 **15 日**，过期需重新下载；以网站后续说明为准。即使扩展名是 `.pdf`，也不保证普通 PDF 软件能够打开。脚本原样下载官方文件，不转换文件，也不修改阅读器权限或有效期。

KXReader 请从网站详情页或网站帮助中心获取。当前详情页提供的是 Windows 版本；其他系统请先确认官方阅读器的支持情况。

### 备用入口

若油猴后台下载不可用，点击 **网站原生下载**。完成权限检查后，面板会显示 **点击开始原生下载** 链接；再手动点击一次，由浏览器处理下载。

这个模式不会显示脚本下载进度。出现链接、弹出新页面或提交下载请求，都不等于文件已经下载完成，请查看浏览器下载记录。

### 下载与资源占用

- **整书请求：**使用网站 `offlineDownload.do` 返回的整书文件，不依赖阅读器当前渲染了多少页。
- **后台传输：**使用油猴 `GM_download`，脚本自身不截屏、不循环渲染页面、不在内存中合并整书。
- **限制重复：**同一标签页一次只启动一个任务；多个标签页之间不会共享任务状态。
- **进度反馈：**按下载接口返回的字节数显示进度；服务器不提供文件大小时，只显示已传输字节。
- **网络重试：**明确的网络错误或超时最多尝试 3 次，使用递增等待；账号权限错误、扩展配置错误和用户取消不会自动重试。
- **取消：**取消按钮会尝试中止当前请求；请同时在浏览器下载记录中确认。
- **续传：**脚本重试会重新请求文件，并不实现字节级断点续传。能否在浏览器下载管理器继续传输，取决于油猴下载模式、浏览器以及服务器是否支持续传。
- **并发：**默认一个整书传输，不额外拆分并发请求。对于已有整书下载入口的站点，这能避免重复生成文件和无谓的内存占用；无法保证突破服务器限速。

文件是整书还是试读文件、可用期限和访问范围由服务器决定。脚本的“下载管理器已报告完成”只表示收到完成回调，**没有校验文件内容、PDF 页数或整书完整性**。

### 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 提示没有确认下载权限 | 打开详情页重新登录，确认网站自己的“下载”按钮可以使用。在线阅读与离线下载可能需要不同权限。 |
| 提示下载功能未启用或扩展名不在白名单 | 在油猴设置中启用下载、允许 `pdf`，或者使用“网站原生下载”。 |
| 提示浏览器下载权限不足 | 按浏览器提示授予油猴下载权限，然后重试。 |
| 下载后是错误页面、极小文件或无法打开 | 在详情页用网站自己的下载按钮复核；确认登录状态和文件大小，并使用 KXReader。下载管理器回调不保证响应内容是图书文件。 |
| 下载中断 | 查看浏览器下载记录能否继续；不能继续时重新下载。登录已失效则先重新登录。 |
| 表单不匹配或网站已改版 | 使用详情页的官方下载按钮。脚本会停止，而不是猜测新的接口。 |
| 普通 PDF 软件打不开 | 官方离线文件可能需要专用阅读器；扩展名不代表它是不受限制的普通 PDF。 |
| 没有出现面板 | 检查脚本是否启用、油猴是否有站点访问权限，确认打开的是 `book.sciencereading.cn` 的 `show.do` 或 `onlineRead.do` 页面，然后刷新。 |

### 实现依据和验证边界

已检查该书公开详情页及公开阅读器脚本，确认官方流程为：

1. `POST /shop/book/Booksimple/checkUserPermission.do`，提交当前书籍 `id`，只有响应文本为 `true` 才继续。
2. 从当前书籍详情页读取 `form1` 的 GET 表单字段，核对书籍 `id`。
3. 按网站 `offlineDownload()` 的行为，把表单提交到 `/shop/book/Booksimple/offlineDownload.do`，并使用权限检查成功后的 `readMark=1`。

脚本复用浏览器会话，不要求输入或复制 Cookie、口令或令牌。它不访问阅读器解密接口、不导出 DRM 密钥、不恢复隐藏的下载控件，也不提取受保护页面。

自动测试使用模拟页面和下载接口回调，覆盖成功、拒绝权限、登录跳转、表单变化、网络重试、取消和重复点击等场景。**尚未在真实油猴扩展和具有下载权限的登录会话中完成该书的整书下载验证。**

## 机械工业出版社：原有脚本

在油猴中新建脚本，粘贴原有 `.js` 文件内容并保存，然后打开 `https://dcd.cmpkgs.com/` 的适用阅读页面。

面板提供自动收集并合并、停止、只合并已捕获页面、回到第一页、清空和状态查看。该版本通过 PDF.js Hook 捕获页面，依赖 CDN 加载 `pdf-lib@1.17.1`。

这个脚本需要页面实际加载 PDF 数据，可能受后台标签页节流影响。**捕获结束不保证整书完整**：查看“状态”中的页码是否齐全，并在下载后检查 PDF。原版本会跳过合并失败的页面，不会因为缺页自动判定失败。

## 开发与测试

需要 Node.js 20 或更高版本。测试依赖仅供开发，不会打包进油猴脚本。

```bash
npm ci
npm run check
npm test
```

在当前云环境中，如果默认 npm 缓存目录不可写，可用：

```bash
npm ci --cache /tmp/download-pdf-books-npm-cache
```

测试文件：[tests/sciencereading.test.cjs](./tests/sciencereading.test.cjs)。测试不下载真实图书，也不需要网站账号。`npm run check` 检查新版脚本语法；`npm test` 使用 jsdom 检查页面交互和官方下载流程。真实站点下载、阅读器兼容性和服务器限速需要单独实测。
